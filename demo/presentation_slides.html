Architecture & Request Flow

+-------------------------------------------------------+ | CLIENT BROWSER | | http://localhost:3000 / Ingress Host | +-------------------------------------------------------+ | v +-------------------------------------------------------+ | NGINX REVERSE PROXY | | - Serves React SPA static assets (/) | | - Proxies API traffic to backend (/api/*) | | - Runs as non-root unprivileged user (UID 101) | +-------------------------------------------------------+ | | v (/api/*) v (/metrics) +---------------------------+ +----------------------+ | FASTAPI BACKEND | | PROMETHEUS SCRAPER | | - REST API Endpoints |--->| Scrapes live metrics| | - Alembic Database Models | +----------------------+ | - UID 10001 (appuser) | +---------------------------+ | v (Port 5432) +---------------------------+ | POSTGRESQL DATABASE | | - Persistent data storage | | - Automated healthchecks | +---------------------------+

Architecture Highlights

  • Single Origin Architecture: Nginx handles routing seamlessly, eliminating CORS issues between frontend and API.
  • Least Privilege Runtime: Neither container runs as root. Backend uses dedicated appuser; Frontend uses nginx-unprivileged.
  • Database Resilience: Docker Compose and Kubernetes employ health checks and readiness probes to ensure the DB is operational before accepting API traffic.

5-Stage CI/CD & DevSecOps Pipeline

🚀 Automated Pipeline Stages

  • Stage 1 (Test): Runs 10 Pytest cases + compiles React frontend.
  • Stage 2 (Build): Builds Docker container images for both services.
  • Stage 3 (Scan): Trivy security scan gates HIGH & CRITICAL CVEs.
  • Stage 4 (Push): Dual push with commit SHA & latest to Docker Hub and GHCR.
  • Stage 5 (Deploy): Deploys to Kind cluster, verifies pod health & executes curl tests.

🛡️ Vulnerability Audit & Defense

  • CVE Identification: Trivy flagged Starlette CVE-2025-62727 (Range header DoS).
  • Defense-in-Depth: Nginx ingress proxy filters and normalizes incoming headers before reaching ASGI handlers.
  • Zero Secret Leaks: Docker tokens & GitHub tokens managed strictly via repository secrets.

Terraform — AWS Infrastructure as Code

🌐 High-Availability VPC Design

  • Multi-AZ: Provisioned across ap-south-1a and ap-south-1b.
  • Public Subnets: 10.20.101.0/24 & 10.20.102.0/24 with Internet Gateway and ELB discovery tags.
  • Private Subnets: 10.20.1.0/24 & 10.20.2.0/24 with NAT Gateway for secure worker outbound traffic.

☸️ Production EKS Cluster

  • Kubernetes 1.31: Control plane managed with public endpoint access.
  • Managed Node Group: t3.medium EC2 instances (Min: 2, Max: 4, Desired: 2).
  • Verification: Clean static validation via terraform fmt and terraform validate. Zero hardcoded credentials via terraform.tfvars.example.
